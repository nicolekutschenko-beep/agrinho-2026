Agrinho 2026

Sobre o projeto

Este projeto foi desenvolvido para o Programa Agrinho 2026 com o objetivo de apresentar a importância da relação entre o campo e a cidade, destacando temas como sustentabilidade, cidadania e preservação do meio ambiente.

O site foi desenvolvido utilizando tecnologias básicas da web, proporcionando uma interface simples, organizada e de fácil navegação.

Funcionalidades

Informações sobre o Agrinho 2026.
Explicação da importância do campo.
Conteúdo sobre sustentabilidade.
Botão para alternar entre Modo Claro** e Modo Escuro.
Layout simples e agradável.

Tecnologias utilizadas

HTML
CSS
JavaScript

Estrutura do projeto


index.html

README.md


Objetivo

Conscientizar as pessoas sobre a importância da preservação do meio ambiente, da agricultura sustentável e da união entre o campo e a cidade, incentivando atitudes responsáveis para um futuro melhor.
